**Авторы:** Ячменев, Аверин  
**Дисциплина:** Логика и основы алгоритмизации в инженерных задачах  

---

### Описание работы

Лабораторная работа посвящена практическому исследованию алгоритмов и их вычислительной сложности:

1. **Задание 1: Экспериментальное исследование времени умножения квадратных матриц**
   - Реализация базового алгоритма умножения матриц $O(n^3)$.
   - Замеры времени работы на матрицах различных размеров.
   - Построение экспериментальных графиков зависимости времени от размера матриц.

2. **Задание 2: Исследование и сравнение алгоритмов сортировки**
   - **Сортировка Шелла (Shell Sort)** с различными шагами.
   - **Быстрая сортировка (QuickSort / алгоритм Хоара)**.
   - **Стандартная библиотечная сортировка C (`qsort`)**.
   - Сравнительный анализ производительности и построение графиков.
