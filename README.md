# Лабораторная работа №2
## Логика и основы алгоритмизации в инженерных задачах

**Авторы:** Ячменев, Аверин  
**Предмет:** Логика и основы алгоритмизации в инженерных задачах  

---

### Состав репозитория:
1. **`alg2lr.cpp`** — исходный код лабораторной работы на C/C++:
   - Задание 1: Экспериментальное исследование времени умножения квадратных матриц ($O(n^3)$).
   - Задание 2: Исследование и сравнение алгоритмов сортировки (сортировка Шелла, быстрая сортировка Хоара, библиотечная `qsort`).
2. **`Лабораторная работа №2 Ячменев, Аверин.pdf`** — полный отчет по лабораторной работе с теоретической частью, таблицами замеров и графиками.

---

### Запуск кода:
Код можно скомпилировать любым компилятором C/C++ (MSVC, GCC, Clang):
```bash
g++ -O2 alg2lr.cpp -o alg2lr
./alg2lr
```
Или открыть файл `alg2lr.cpp` в среде Visual Studio и запустить (`Ctrl + F5`).
