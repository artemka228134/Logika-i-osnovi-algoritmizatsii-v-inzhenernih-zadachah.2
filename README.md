### Как открыть и запустить проект в Visual Studio:
1. Скачайте репозиторий (зеленая кнопка **Code → Download ZIP** или через `git clone`).
2. Дважды кликните по файлу **`alg2lr.slnx`** (или откройте его через Visual Studio 2022 / 2025).
3. Проект и исходный файл `alg2lr.cpp` автоматически откроются со всеми необходимыми настройками компилятора.
4. Выберите конфигурацию **Release** или **Debug** (платформа `x64`).
5. Нажмите **`Ctrl + F5`** для сборки и запуска программы.
